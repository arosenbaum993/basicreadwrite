# Basic Reading/Writing Curriculum Dashboard

Full-year dashboard for Basic Reading/Writing I-IV. The first screen is the curriculum map, organized by quarter and unit. Each unit card opens a clickable teacher-created resource document with:

- elements taught
- mini-lesson moves
- teacher-created materials
- student tasks
- checks for understanding
- differentiation supports

## GitHub Pages

The published site lives in `docs/index.html`.

To publish it:

1. Open this repository on GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to `main` and the folder to `/docs`.
5. Click **Save**.

GitHub will publish the dashboard at:

`https://arosenbaum993.github.io/basicreadwrite/`
